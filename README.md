# S7venloungeetabacaria

Crie pra mim um catálogo digital tanto para celular quanto para computador que contém as seguintes coisas 

🛍️ Catálogo de produtos

🔎 Busca por produto

📂 Categorias

🛒 Carrinho de compras

💰 Cálculo automático do total

📍 Campo para endereço do cliente

💳 Forma de pagamento

📲 Pedido enviado diretamente pelo WhatsApp

📱 Layout adaptado para celular

💾 Carrinho salvo no aparelho
